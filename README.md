# EcoTrack — Sustainable Lifestyle Recommendation Website 🌱

EcoTrack helps people find practical, affordable ways to make everyday life more sustainable. It is a lightweight, responsive static website built with HTML, CSS, and vanilla JavaScript.

## Features

- **Personalized recommendations:** Tailors and ranks ideas using travel, diet, home-energy use, food-waste habits, budget, effort level, and personal priorities.
- **Practical alternatives:** Suggestions cover food, travel, home energy, re-use, repair, shopping, and recycling.
- **Environmental context:** Explains likely benefits without promising unsupported numerical carbon savings.
- **Seven-day action plan:** A simple checklist with progress tracking.
- **Save ideas:** Save and revisit recommendations.
- **Filters:** Browse recommendations by category.
- **Privacy-conscious by design:** No account, analytics, or backend required. Preferences and checklist progress are stored locally in the user's browser when browser storage is available.
- **Responsive and accessible:** Keyboard-visible focus states, semantic page structure, labeled controls, reduced-motion support, and layouts for mobile and desktop.
- **Fast static delivery:** No framework, build step, external font, image, or JavaScript dependency is required.

## Run locally

Open `index.html` in a browser, or serve the repository with any static HTTP server.

## Environmental recommendation note

The recommendations describe general, context-dependent benefits. Real-world outcomes vary with local electricity generation, transport options, product lifetime, food choices, waste systems, and user circumstances. EcoTrack does not claim to calculate a verified personal footprint or guarantee specific savings.
